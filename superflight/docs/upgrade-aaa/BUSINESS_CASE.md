## 📈 Revenue Projections (Conservative Scenario)

### Model: Premium Game ($9.99 one-time purchase)

```
MONTH 1 (Launch)
├─ Press coverage / reviews
├─ Influencer coverage
├─ App Store feature (Games tab)
├─ Organic + paid ads
└─ Downloads: 150k
   Revenue: 150k × $9.99 × 0.70 (Apple cut) = $1.05M

MONTH 2-3 (Momentum)
├─ Word of mouth building
├─ Seasonal updates (new enemies, levels)
├─ Cosmetics DLC ($2.99, optional)
└─ Downloads: 80k/month
   Revenue: ($80k × $9.99 × 0.7) + ($30k cosmetics) = $589k/month

MONTH 4-6 (Sustained)
├─ Core audience locked in
├─ Challenge seasons (free/paid)
├─ Cosmetics vault growing
└─ Downloads: 40k/month
   Revenue: ($40k × $9.99 × 0.7) + ($50k cosmetics) = $329k/month

MONTH 7-12 (Evergreen)
├─ Long-tail revenue
├─ Minimal marketing spend
├─ Cosmetics driven
└─ Downloads: 20k/month
   Revenue: ($20k × $9.99 × 0.7) + ($80k cosmetics) = $220k/month

YEAR 1 TOTAL:
$1.05M + ($589k × 2) + ($329k × 3) + ($220k × 6) = $4.95M
```

**Conservative 12-month revenue**: **$5M gross**  
**After Apple cut (30%)**: **$3.5M net**

```

```

**Monthly recurring**: 15% of active players buy cosmetics  
**Average cosmetics spend per buyer**: $5.99/month

**Year 1 projection with cosmetics**:
- Base game revenue: $1.8M (after cut)
- Cosmetics revenue: $2.1M
- **Total Year 1**: $3.9M net

### Model: Premium Game + Battle Pass (Alternative)

```
Base game: Free (supported by cosmetics)
Battle Pass: $9.99/season (12-week season)
Cosmetics: $2.99-$7.99
Premium currency: $0.99-$99.99 packs
```

**Potential Year 1**: $5-8M net (higher volatility, requires live service expertise)

**Recommendation**: Stick with **Premium Game + Optional Cosmetics** (lower risk, clearer positioning).
